# Problem 1: Sales Forecasting
📂 Dataset: Sales Forecast
# Problem Statement
You are given historical sales data over time.
Your task is to predict future sales based on past trends.
# Tasks to Perform
 1.Load the dataset
 2.Convert date column into useful features
 3.Handle missing or inconsistent data
 4.Select relevant features
 5.Train a regression model
 6.Evaluate model performance using regression metrics
 7.Explain how time-related features influence sales prediction
# Note: Focus on decision-making and understanding of data, not maximum accuracy.
